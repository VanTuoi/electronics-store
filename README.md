# Electronics Sales App

This is my learning project which involves building and testing an electronics sales app while ensuring good coding:

## About this project

This is a React app built using the following technologies and libraries:

- Vite
- Bootstrap
- React Router

Please follow the instructions below carefully to set up this project on your machine.

## Run the app

You can run the React app using the following commands:

```bash
# Install dependencies

npm install

# Start the development server
npm run dev
```
