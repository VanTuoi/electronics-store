# Electronics Sales App / Ứng dụng Bán Hàng Điện Tử

An electronics e-commerce application built with React and modern technologies.
Ứng dụng bán hàng điện tử được xây dựng với React và các công nghệ hiện đại.

## About / Giới thiệu

This is a React application built with the following technologies and libraries:
Đây là một ứng dụng React được xây dựng với các công nghệ và thư viện sau:

- [Vite](https://vitejs.dev/) - Modern build tool and dev server / Build tool và dev server hiện đại
- [Bootstrap](https://getbootstrap.com/) - CSS Framework for responsive design / Framework CSS để tạo giao diện responsive
- [React Router](https://reactrouter.com/) - Routing library for React / Thư viện routing cho React

## Installation & Setup / Cài đặt và Chạy ứng dụng

### System Requirements / Yêu cầu hệ thống

- Node.js (version 14.0 or higher / phiên bản 14.0 trở lên)
- npm or/hoặc yarn

### Installation Steps / Các bước cài đặt

1. Clone the repository / Clone repository này về máy:

```bash
git clone <repository-url>
```

2. Navigate to project directory / Di chuyển vào thư mục dự án:

```bash
cd electronics-sales-app
```

3. Install dependencies / Cài đặt các dependencies:

```bash
npm install
# or/hoặc
yarn install
```

4. Start development server / Khởi chạy môi trường development:

```bash
npm run dev
# or/hoặc
yarn dev
```

The application will run at / Ứng dụng sẽ chạy tại: `http://localhost:5173`
